## 七、自动化
- **调度器(多时区)**:A股按北京(nightly 02:00 / daily 15:30盘后 / morning 09:35开盘执行 / weekly) · 美股按美东(us_daily 17:30盘后)
- **健康巡检**:A股实时接口定时体检(防静默失效)
- **多设备**:一主一从(主机跑调度 · 开发机 `AFR_SCHEDULER_ENABLED=0`)· 代码走git · 数据走快照 · schema走migrations
- **保障**:WAL看门狗 · keepalive守护 · 过期待办开机补跑

## 重设计可参考的"痛点清单"
1. **导航平铺**:11项不分市场/任务 → 建议按 概览/A股/美股/全球/研究/学习/系统 分组
2. **三市场体验不统一**:A股详情很厚(6 Tab)、美股详情另一套、全球又一套 → 可统一详情页骨架
3. **实验模块藏得深**:回测/模拟盘/因子都在一个入口里 Tab 切 → 重设计可提权或重组
4. **入口冗余**:/、/dashboard-v2、/landing 三个概览级页面 → 需厘清主入口
5. **颜色语义**:A股红涨绿跌、美股绿涨红跌并存 → 新美学要统一规则并明确标注
