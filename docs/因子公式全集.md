# 因子公式全集

模拟持仓每个组合的选股依据 = 某个因子/评分的排序取 top-N。本文档给出**每个因子的确切计算公式**(源自代码,非泛述)。

> 档位制说明:多个维度先算成 **tier ∈ {−2,−1,0,+1,+2}**,再映射成 0–100 分:`分 = (tier+2)×25`(−2→0,0→50,+2→100)。反向 `pct→tier`:≥75→+2,≥60→+1,≥40→0,≥25→−1,else −2。

---

## 一、V5 十维评分体系(8 个组合用)

8 个组合(综合/基本面/质量/估值/技术/资金/行业景气/指数增强)都取 `comprehensive_scores` 里的维度分,选 top-N。各维度每晚全市场重算。

### 1. 综合分 composite_v5 —— `services/v5_scorer.py`
```
base = Σ( tier_to_pct(dim_tier) × weight ) / Σ weight     # 加权求和
composite_v5 = clip( base − 短板惩罚 , 0, 100 )           # 再扣短板、过 veto
```
**十维权重 V5_WEIGHTS**(和为 1.0):

| 维度 | 权重 | 维度 | 权重 |
|---|---|---|---|
| 基本面 fundamental | 0.20 | 技术面 technical | 0.10 |
| 质量 quality | 0.15 | 大盘环境 market_env | 0.10 |
| 资金面 capital | 0.15 | 政策面 policy | 0.05 |
| 行业景气 industry | 0.10 | 新闻面 news | 0.03 |
| 估值 valuation | 0.10 | 情绪面 mood | 0.02 |

**累进短板惩罚**(`_shortboard_penalty`):每出现一个 −1 维度依次扣 `3/5/8`,每个 −2 维度依次扣 `10/15`,**总扣封顶 30**。
**一票否决 veto**:重大负面(如财务造假/退市风险)→ `exclude`,直接踢出候选。

### 2. 基本面 fundamental —— `services/factor_engine.py`
盈利 + 成长 + 价值 + 安全 四子项合成。核心两子:
```
成长 growth = 0.40×营收CAGR分位 + 0.40×净利CAGR分位 + 0.20×EPS增速分位
价值(子) = 0.30×PE分位⁻¹ + 0.25×PB分位⁻¹ + 0.15×股息率分位 + 0.20×PEG分位⁻¹ + 0.10×PS分位⁻¹
```
(`分位⁻¹` = 逆序分位,越便宜分越高;分位均为**同行业**横截面)

### 3. 质量 quality —— `services/factor_engine.py._calc_quality`
```
quality = 0.40×ROE分位 + 0.25×毛利率分位 + 0.25×净利率分位 + 0.10×ROIC分位
亏损股切换权重: ROE 0.50 / 净利率 0.35 / ROIC 0.15 (毛利不计)
```

### 4. 估值 valuation —— `services/valuation_scorer.py`
```
估值分 = 0.5×PE分 + 0.3×PB分 + 0.1×股息率分 + 0.1×PEG分
```
- **PE分**(行业PE分位 pe_pct):<10%→95,<30%→80,<70%→60,<90%→40,else 20;
  亏损股→基准 30 + `(0.5−PB分位)×20` 修正
- **PB分** = `100×(1 − PB行业分位)`
- **股息率分**:高于行业均值+1σ→+20,高于均值→+10,低于均值−1σ→−10
- **PEG分**:由成长因子的 PEG 修正得到

### 5. 技术面 technical —— `services/technical_rule_engine.py`
```
technical_tier = fuse( 0.4×趋势档 + 0.3×动量档 + 0.3×量能档 )
每模块子分求和后经 _subtotal_to_tier: ≥2→+2, ≥0.75→+1, >−0.75→0, ≥−1.75→−1, else −2
```
- **趋势** = MA排列 + 价格位置 + ADX
  - MA排列:MA5>10>20>60→+2,MA5>10>20→+1,空头倒排→−2/−1
  - 价格位置(close/MA20):>1.08→+1,>1.02→+0.5,0.98–1.02→0,0.92–0.98→−0.5,<0.92→−1
  - ADX:ADX>阈值且 +DI>−DI→+1,反之−1
- **动量** = RSI档 + MACD档 + 5日收益档
  - RSI:超买→−1/−0.5,中性→0,超卖→+0.5/+1
  - MACD:红柱且金叉≤10日→+1;绿柱且死叉≤10日→−1
  - 5日收益:过热→−1/−0.5,正常→0,超跌→+0.5/+1(**反向**:追涨扣分)
- **量能** = 量比档 + 量价相关档 + 突破档

### 6. 资金面 capital —— `services/capital_scorer.py`
```
capital = 0.45×资金流分 + 0.30×换手分 + 0.25×涨跌分   (clip 0–100)
资金流分 flow = clip( (量能分位×0.5 + 动量×10 + 0.5) × 100 , 0, 100 )
换手分:换手分位∈[0.5,0.8]→70+(x−0.5)×30;>0.9→惩罚衰减;<0.1→低分
涨跌分:涨→50+min(|涨幅|×2,15);跌→max(20, 50+涨幅×2)
```
另有主力资金分档(`main_net_5d`):>5千万→+2,>0→+1,<−5千万→−2,<0→−1。

### 7. 行业景气 industry
所属**行业**层面的资金流 + 相对强度(行业动量),映射成档位。个股继承其行业景气档。

### 8. 大盘/政策/新闻/情绪(小权重维度)
- **market_env(0.10)**:指数趋势 + 市场广度 → 全市场统一档
- **policy(0.05)**:所属行业的政策事件影响(LLM 事件分类)
- **news(0.03)**:个股新闻情绪,由事件强度 `event_intensity` 累加成档,clip 到 ±2
- **mood(0.02)**:波动率 + 动量的横截面分位

### 指数增强 index_enhance
= 在基准成分/行业约束下,选 composite_v5 高分股(目标跑赢指数),用同一套 V5 分。

## 二、独立策略因子(6 个组合用)

### 动量 momentum —— `services/technical_rule_engine`(现算)
```
momentum = 10日累计收益 + 低波动加分(1/σ) + 量能稳定加分
淘汰规则: 20日动量<0 且 10日动量<20日动量(加速下行) → 直接剔除
```
只要"稳步上涨",不要"冲高回落"。

### 双均线 dual_ma —— 因子 F031
```
F031 = +1 (金叉: 短均线上穿长均线) / −1 (死叉) / 中间态 ∈[−1,1]
选股: 取 F031 ≥ 0.5 的金叉股 → 再按 composite_v5 降序取 top-N
```
(技术金叉打底 + 基本面择优)

### 反转 reversal —— 因子 F020
```
F020 = 超跌反转信号(近期跌幅/偏离度,值越高反弹潜力越大)
选股: F020 ≥ min_score 且 质量分 ≥ 40(过滤基本面差的,不接飞刀)
```

### 海龟 turtle —— `services/strategies/turtle.py`
```
通道 = 前 20 日(不含当日)最高价
突破上轨 → 高分; 通道内 → 按相对位置线性映射 0–100
入场: 收盘突破 20 日高点; 出场: 跌破 10 日低点(通道止损)
```

### 红利防御 dividend_defensive —— `services/strategy_selector.py`
```
分数 = 0.4×质量分 + 0.3×估值分 + 0.3×min(股息率×10, 100)
入池门槛: 股息率 ≥ 2% 且 质量分 ≥ 50
```

### 行业轮动 sector_rotation
选近期**相对强势的行业**,在强势行业内挑个股(每行业限 2 只),吃行业轮动。

## 数据来源与更新
- V5 十维分:每晚 nightly 任务全市场重算 → `comprehensive_scores` 及各维度表(`capital_scores`/`val_score`…)
- F020/F031 等因子:每日增量算入 `factor_values`
- 动量/海龟:选股时用日线**现算**,不依赖预存表
- 分位(percentile)默认**同行业横截面**,估值/资金部分用全市场
