# ML 预测状态：已关闭（experimental / off）

**结论（2026-07-25）**：LightGBM 排序模型在本平台 A 股票池上**无可持续 alpha**。经 v1 / v2(P1) / v3 三版 walk-forward 验证,均未达标。**ML 预测已关闭,不参与 V5 综合分,不推广。** 除非有实质新证据(新数据源 / 不同标的域),不再迭代特征工程。

---

## 三版对照(H20,LightGBM,同窗口参数)

| 版本 | 特征思路 | 24 折 mean RankIC | 全历史 mean | 判定 |
|------|----------|-------------------|-------------|------|
| **v1** | 技术+基本面 raw | 0.0324 | ~0.002(123折) | 短窗像运气,全历史≈0 |
| **v2 (P1)** | + 缺数填充 + miss flag + illiq_20 | **0.0164** | — | 近窗**腰斩**,缺数不是病灶 |
| **v3** | 行业中性(行业内分位)替换 raw 基本面,砍 miss flag | **0.0071** | 0.0071(24折) | **三版最弱**,行业中性无效 |

- 目标线:24 折 mean RankIC ≥ **0.025**。三版全部未达。
- 共性:**末折崩**(v2/v3 末折均从 +0.08 级跌到 −0.08~−0.11),正 IC 折占比 ~50-55%(≈抛硬币),方差 0.11-0.25。
- 诊断:**信号本身弱且时变**,不是缺数噪声、也不是行业混淆主导。特征工程救不回。

## 为什么停

1. v1→v2(缺数)→v3(行业中性)是三个**不同假设**,全部证伪——不是没试对方向,是方向对了也无 edge。
2. 全历史均值 ≈ 0 意味着长期无排序能力;近窗偶尔转正是抽样运气(已被门控硬化拦截,见下)。
3. 继续挖特征是边际递减 + 过拟合风险。**预设 kill 线**在开跑前定死,结果触发,干净收尾。

## 现在的安全状态(即使有人想开也开不了)

- **`AFR_QLIB_PREDICTIONS_APPROVED=false`**(`.env`,本地)—— 强制关闭 ML 消费。
- **门控硬化**([`services/ml_gate.py`](../backend/services/ml_gate.py)):除近窗均值/σ外,新增
  - 全历史均值下限 `AFR_ML_GATE_MIN_FULL_MEAN_RANK_IC`(默认 0.01)
  - 前后折漂移上限 `AFR_ML_GATE_MAX_DRIFT`(默认 0.05)
  - **按 `model_version` 隔离评估**(只认最新版本,v1/v2/v3 折不混算)
  - 实测:v3 gate_passed=`false`(full_mean 0.0071<0.01 + std + drift 三关齐否)
- 一句话:近窗再走运,也过不了全历史 + 漂移这两关。

## 保留的干净基础设施(留着无害)

- `variant` 参数管线(`feature_names_for/vectorize/apply_cross_section_ranks` + `run_h20_walkforward`)—— 以后要试新特征集,加个 variant 即可,不动老版本。
- `_industry_percentile()` 行业内分位工具(无未来偏差,仅用当日截面)。
- `ml_impute.py`(P1 的缺数填充 + winsorize)。
- 全部单测在 `tests/test_ml_gate.py` / `test_ml_impute.py`。

## 若将来重启 ML(需满足其一)

- 新增**正交数据源**(如高频订单流、另类数据),而非在现有字段上再造特征。
- 换**标的域**(如只做流动性 top 20% 或单一板块),信号可能更稳。
- 任何重启都必须**先定 kill 线**,并让全历史 + 漂移门控背书,不许只看近窗。
