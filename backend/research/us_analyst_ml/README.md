# 美股分析师(券商级)评级质量建模 —— Phase 1/2 归档

**状态:2026-08-21 实验结论 — 暂不产品化(ML 转内部研究)。Phase 3 阻塞,等待新数据源。**
**INTERNAL_RESEARCH_ONLY — 产出的 us.db 表与预测严禁被 api/前端引用。**

## 目标
用 ML 预测「券商买入评级的兑现质量」,把详情页的 naive 分析师共识升级成可信度加权信号。
注:数据源 yfinance `upgrades_downgrades` 只有 **券商(Firm)级**,无分析师个人 id —— 个人级需 I/B/E/S。

## 数据地基(留存,可复用)
- `phase1_build_events.py` → 表 `us_rating_events`:S&P100、**41,923 条**满 12 个月的评级事件、**210 家券商**、99 只票。
- 标签:12 个月**超额收益 vs 行业 ETF**(XLK/XLF/… 回退 SPY),复权消除拆股,严格 point-in-time。
- `phase2_model_cv.py` → LightGBM 双头(分类:是否跑赢行业;回归:12月超额)+ 12 折**扩展窗口时序 CV** + 增益/排列重要性。
  - 内部产物:`us_rating_ml_oof_internal`(25,753 行 OOF 预测)、`us_rating_events.ml_high_conviction`(2,576 条 top10% 标记)。

## 关键结论
1. **模型作为通用排序器不成立**:OOF AUC **0.542**(门槛 0.58),RankIC≈0 —— 不能平滑排序,只能识别极端尾部。
2. **仅 top-decile 有真信号**:最高置信 10% 的买入平均超额 **+17.1%、68% 跑赢行业**;但 D0–D7 完全乱序(单边尾部,无空头信号)。
3. **"券商技能"被证伪为主导因素**:Phase 1 的券商能力自相关 r=0.304,大部分是"券商专攻低波动股"的混淆;一旦加入股票波动率/目标溢价/市场 regime,**情境类特征(vol60/target_premium/vix/secmom20)主导,券商类只剩边际贡献**。

## 失效边界(= Phase 3 路线图)
上线前跨市场安检,top-decile 踩了两个崩盘场景:
- **[年份] 2025 反转:−19% 超额 / 34% 胜率**(样本外最新年,最接近实盘 —— 致命)。2014–2024 全为正(+4%~+60%)。
- **[行业] 可选消费 XLY:−5.0% / 28% 胜率**;且 66% 信号集中在科技(XLK)+通信(XLC)。
- [VIX] 低/中/高波动三档全正(+13%~+22%)—— 这一维过关。

**诊断**:模型过拟合过去十年科技/通信牛市,缺**宏观制度因子**(利率、美联储、行业轮动),在 2025(高利率+AI 分化+消费疲软)制度切换时翻车。

## 决策依据
上线前预先约定:「若 top-decile 在任一场景崩盘(超额≤0 或胜率≤50%)→ 转内部研究,不对外」。踩中 2025 + XLY 两个崩盘场景 → **止损,不上线徽章**。透明披露(路径2)也否决:金融工具里用户只记绿标签、不读免责小字,坏信号比没信号更具破坏性。

## Phase 3 重启条件(不满足则不再调参/扩样)
必须先接入**新信息源**:①财报超预期(earnings surprise);②分析师报告/新闻文本情感(NLP);③宏观制度因子(利率/轮动)。在现有特征上继续在 S&P500 调参只会制造更隐蔽的过拟合。
